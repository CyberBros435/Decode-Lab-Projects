A Python command-line application that demonstrates the fundamentals of **Symmetric-Key Cryptography** by implementing a randomized **Monoalphabetic Substitution Cipher**. The program generates a new random substitution key during every execution, encrypts the user's plaintext, and then decrypts it back using the **same key**, illustrating the core principle behind symmetric encryption.

> **Note:** This project is intended for **educational purposes only**. It demonstrates the concepts of classical cryptography and is **not suitable for securing real-world sensitive information**.

# ⚙️ How It Works

The application follows three main stages.

## 1. Key Generation

A random substitution key is generated by shuffling the standard English alphabet.

Example:

```text
Original Alphabet

abcdefghijklmnopqrstuvwxyz
```

```text
Generated Secret Key

qwjklzxtcnmyivghbupdrsaefo
```

Each execution produces a completely new key.

---

## 2. Encryption

For every character:

1. Find its index inside the original alphabet.
2. Replace it with the character at the same position in the secret key.

Example

```text
Plaintext

hello
```

↓

```text
Ciphertext

dkzzu
```

*(Output varies every execution because a new random key is generated.)*

---

## 3. Decryption

During decryption:

1. Find the encrypted character inside the secret key.
2. Replace it with the character located at the same index in the original alphabet.

Using the same secret key restores the original plaintext.

# ⚠️ Limitations

This project is designed for educational purposes and has several limitations.

- **Not cryptographically secure.**
- Vulnerable to frequency analysis attacks.
- Generates a new key every execution.
- Original letter casing is not preserved.
- Supports only lowercase English alphabet characters.
- Numbers and uppercase letters are not encrypted.
- No secure key exchange mechanism.
- Not suitable for protecting sensitive or confidential information.
