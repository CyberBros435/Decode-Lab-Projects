# Phishing Red Flag Checklist

Use this checklist when reviewing a suspicious email or message.

- [ ] Unexpected message
- [ ] Suspicious sender address
- [ ] Sender/domain does not match the claimed organization
- [ ] Urgent or threatening language
- [ ] Request for a password or credentials
- [ ] Request for financial information
- [ ] Suspicious hyperlink
- [ ] Link destination does not match the claimed organization
- [ ] URL shortener hides the destination
- [ ] Unexpected attachment
- [ ] Poor or unusual wording
- [ ] Impersonation of a trusted organization
- [ ] Unusual request
- [ ] Pressure to act immediately

## Basic Rule

If several indicators are present, stop and verify the message through a trusted channel before taking action.
