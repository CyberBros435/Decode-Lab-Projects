# Analysis 03 — Phishing

**Sample:** `phishing_03.txt`

## Classification
**PHISHING**

## Red Flags
1. The unexpected prize is a common social-engineering lure.
2. The message uses a shortened link.
3. The destination is not transparent.
4. It requests personal and account information.
5. It creates pressure to claim the reward.

## Suspicious Keywords
- Congratulations
- Won
- $1,000
- Claim your prize
- account information

## Why It Is Unsafe
The recipient was not expecting the reward, the shortened URL hides the final destination, and the message requests personal information. These combined indicators make the message unsafe.

## Recommended Action
Do not open the shortened link or provide personal information. Report the message as suspicious.
