# Analysis 01 — Phishing

**Sample:** `phishing_01.txt`

## Classification
**PHISHING**

## Red Flags
1. The message creates strong urgency.
2. It threatens account suspension.
3. It asks the user to verify a password.
4. The sender domain is suspicious and uses a look-alike spelling.
5. The login link points to a suspicious domain.

## Suspicious Keywords
- URGENT
- suspended
- verify your password
- immediately
- permanently

## Why It Is Unsafe
The message combines impersonation, urgency, a credential request, and a suspicious login link. These indicators strongly suggest an attempt to obtain account credentials.

## Recommended Action
Do not click the link or provide credentials. Report the message to the security/IT team.
