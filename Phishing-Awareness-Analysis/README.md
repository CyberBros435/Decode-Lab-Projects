# Phishing Awareness Analysis

## Internship Project 3 — Cyber Security

### Objective
Analyze sample emails/messages to identify phishing attempts by:
- Identifying suspicious links or keywords
- Listing red flags
- Explaining why a message is unsafe

This project follows the requirements of the DecodeLabs Cyber Security Project 3 brief.

## Methodology

Each message is reviewed for:
1. Sender information
2. Subject
3. Suspicious keywords
4. Links and visible destinations
5. Urgency or threats
6. Requests for credentials or sensitive information
7. Impersonation indicators
8. Overall risk and classification

## Safety

All examples in this repository are fictional training samples. No real credentials are requested or collected.

## Expected Learning Outcome

After completing this project, the analyst should be able to recognize common phishing indicators, explain why a suspicious message is unsafe, and recommend an appropriate defensive action.
