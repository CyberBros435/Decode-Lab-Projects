# Project Report — Phishing Awareness Analysis

## 1. Introduction

Phishing is a social-engineering technique in which deceptive messages are used to manipulate users into taking an unsafe action. This project focuses on analyzing sample messages and identifying indicators of phishing.

## 2. Project Goal

The goal is to analyze sample emails/messages and:
- identify suspicious links or keywords;
- list red flags;
- explain why a message is unsafe.

## 3. Analysis Process

Each sample was reviewed using the following process:

```text
Message
   ↓
Sender and subject review
   ↓
Keyword and language review
   ↓
Link review
   ↓
Red-flag identification
   ↓
Risk assessment
   ↓
Phishing / Legitimate classification
   ↓
Recommended action
```

## 4. Results

| Sample | Classification | Risk | Main Indicators |
|---|---|---|---|
| phishing_01 | Phishing | High | Urgency, suspicious domain, credential request |
| phishing_02 | Phishing | High | Fake delivery notice, suspicious link, payment request |
| phishing_03 | Phishing | High | Prize lure, shortened URL, personal-information request |
| legitimate_01 | Legitimate | Low | Normal communication, no suspicious credential request |

## 5. Key Phishing Indicators

The analysis identified common warning signs such as:
- urgent or threatening language;
- suspicious sender domains;
- requests to verify credentials;
- suspicious links;
- requests for payment or personal information;
- unrealistic rewards or prizes;
- pressure to act immediately.

A single indicator does not automatically prove that a message is malicious. Indicators should be considered together with the message context.

## 6. Recommended User Response

When a message appears suspicious:
1. Do not click suspicious links.
2. Do not provide passwords or sensitive information.
3. Verify the request using an independent trusted channel.
4. Report the message to the appropriate security/IT team.
5. Delete or quarantine the message according to organizational procedure.

## 7. Conclusion

This project demonstrates basic phishing-awareness and threat-analysis skills. The completed analysis shows how suspicious communication can be identified through sender information, language, links, and requested actions.
